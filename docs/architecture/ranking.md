# Transparent Ranking

Every post in the DegenFeed timeline includes an explanation of why it appears there.

## Scoring Factors

| Factor | Weight | Source |
|--------|--------|--------|
| Recency | 40% | Post timestamp |
| Protocol Reach | 20% | Normalized engagement across protocols |
| Personal Network | 25% | Accounts you follow / interact with |
| Content Type | 10% | Media, text, link — user preference |
| Diversity Boost | 5% | Ensure protocol diversity in feed |

## Transparency

Each post carries a `ranking` field in the API response with a breakdown of scores. Click "Why this post?" in the UI to see the breakdown.
